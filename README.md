# Дневник роста

## Что это
Личный трекер целей с AI-обратной связью, достижениями и еженедельными отчётами.

## Как запустить локально (необязательно, если сразу деплоишь на Vercel)
1. Установи Node.js (nodejs.org)
2. В папке проекта: `npm install`
3. Скопируй `.env.example` в `.env.local` и впиши свой ключ Anthropic API
4. `npm run dev` — открой http://localhost:3000

## Как разместить в интернете (Vercel)
1. Загрузи это репозиторий на GitHub
2. Зайди на vercel.com, войди через GitHub
3. "New Project" → выбери этот репозиторий
4. В настройках добавь переменную окружения: `ANTHROPIC_API_KEY` = твой ключ
5. Deploy

## Важно про ключ API
Никогда не пиши ключ прямо в коде — он попадёт на GitHub и его увидят посторонние.
Ключ должен быть только в переменных окружения (Vercel Settings → Environment Variables).

## Текущее состояние
- Данные хранятся в браузере пользователя (localStorage) — пока без общей базы данных
- Вход через Google — пока визуальная заглушка (не настоящая авторизация)
- Следующие шаги: подключить настоящую базу данных (Supabase) и настоящий Google OAuth,
  чтобы прогресс сохранялся за аккаунтом на любом устройстве
